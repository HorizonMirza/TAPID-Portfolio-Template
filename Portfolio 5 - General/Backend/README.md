# Backend

Template dibangun menjadi HTML statis di Astro. Proses build memvalidasi file data di `Frontend/src/portfolio.json` melalui `Frontend/src/portfolio.ts`. Vercel menyajikan hasil build.

Respons Google Form menjadi bahan awal bagi TAP.ID. Akses serta pengelolaan respons dilakukan di Google Forms. Gunakan hanya data yang disetujui pelanggan untuk ditampilkan ketika mengisi file portofolio.
