# Technology

- Edit client content in `Frontend/src/portfolio.json`. Keep both `id` and `en` for bilingual text.
- Follow the schema in `Frontend/src/portfolio.ts`. Run `npm run check` and `npm run build` from `Frontend`.
- Preserve the theme’s visual identity, keyboard navigation, and responsive layout in both light and dark modes.
- Use fictional content in this template repository. Publish assets and contact information on client sites only with the client’s approval.
- Update the documentation when the data contract or deployment steps change.
