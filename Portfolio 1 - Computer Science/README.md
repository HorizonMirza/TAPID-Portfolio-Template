# Technology Portfolio Template

A blue template for developers, engineers, and other technology professionals.

| Default palette | Typeface | Demo profile |
| --- | --- | --- |
| Blue | Space Grotesk | Arga Pradana |

## Run locally

Open `Frontend` in this theme using Node.js 24 LTS.

```sh
npm ci
npm run dev
```

Open `/` for Indonesian or `/en/` for English.

## Customize and deploy

Edit [portfolio.json](Frontend/src/portfolio.json) to update the profile, education, projects, skills, experience, theme preferences, Resume CV, and footer links.

- [Client setup, build, deployment, and handoff](Documentation/PANDUAN.md)
