# Portfolio 2 - Asuransi

- Edit konten pelanggan di `Frontend/src/portfolio.json`. Pertahankan pasangan bahasa `id` dan `en`.
- Gunakan aturan data di `Frontend/src/portfolio.ts`. Uji dengan `npm run check` dan `npm run build` dari `Frontend`.
- Pertahankan identitas visual tema Asuransi, navigasi keyboard, serta tampilan responsif dalam mode terang dan gelap.
- Gunakan data demo fiktif di repositori template. Masukkan ke website pelanggan hanya aset dan kontak yang pelanggan setujui untuk ditampilkan.
- Perbarui dokumentasi jika kontrak data atau langkah deployment berubah.
