# Visual demo

Visual `Frontend/public/media/bentuk-bebas.webp` dibuat dengan ImageGen bawaan untuk studi poster fiktif.

>A horizontal 4:3 art-directed portfolio case-study cover for a fictional Indonesian visual communication designer. Single sculptural scene in vivid vermilion red, offwhite and near-black: a large folded paper geometric shape like an abstract bird or burst, casting a graphic diagonal shadow on a flat vermilion ground, with a few cut-paper fragments at the lower right. Sophisticated Bauhaus and contemporary Indonesian print studio sensibility, tactile coarse risograph-like paper fibers, clean directional spotlight, good editorial imagery with the object centered and room to crop. Graphic and energetic, physical photographed material. No words, no letters, no markings, no watermarks, no human subjects.
