# Portfolio 3 - Management

Template portofolio bilingual TAP.ID dengan font **Manrope**. Buka folder `Frontend` dan jalankan:

```sh
npm ci
npm run dev
```

Edit profil, proyek, keahlian, pengalaman, kontak, dan warna di `Frontend/src/portfolio.json`.
